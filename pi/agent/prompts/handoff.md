---
description: Summarize work so another session can continue
---
Create a concise development handoff for the current task. Inspect the current branch and working tree when available, then include:

- Goal and current status
- Files changed and important implementation details
- Decisions, assumptions, and constraints
- Validation already run and its results
- Remaining work, known issues, and risks
- Exact suggested next steps or commands

Do not modify files. Make the handoff self-contained enough for a fresh Pi session or another developer to continue.
